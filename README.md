# 📄 CV Diego Peyrano

Aplicación web desarrollada en **React + TypeScript** para presentar mi currículum vitae de forma interactiva, moderna y responsive, con soporte multilenguaje y exportación a PDF.

---

## ✨ Características

- 📱 Diseño responsive (desktop y mobile)
- 🌍 Soporte multilenguaje (ES / EN)
- 🧭 Navegación por secciones con scroll suave
- 🎨 Interfaz moderna con Material UI
- 🎬 Animaciones con Framer Motion
- 📄 Exportación a PDF del CV
- 🧠 Separación por componentes reutilizables
- 🔧 Arquitectura clara y mantenible

---

## 🧩 Secciones del CV

- 🧑‍💼 Header (nombre y rol)
- 📝 Resumen profesional
- 💼 Experiencia laboral
- 🛠️ Habilidades técnicas
- 🎓 Educación
- 📬 Contacto
